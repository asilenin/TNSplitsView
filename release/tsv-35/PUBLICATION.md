# Публикация TSV-35

22 октября 2026 года владелец подтвердил публикацию версии **1.4.0** в Garmin Store: загружены .iq, скриншоты, release notes и Hero Image. Это сообщение владельца; страницу Store чат независимо не проверил.

Владелец подтвердил проверку интерфейса на физических fr965. Проверка записи лактата в FIT ещё не выполнена. Для неё остаются две сохранённые тренировки: замер при идущем таймере с продолжением не менее 10 секунд и замер после Stop с сохранением без возобновления. Затем владелец явно поручил закрыть TSV-35 без этой проверки: возможные проблемы будут оформлены новой задачей. FIT не считается проверенным и по решению владельца не блокирует закрытие.

Код выпуска: 541ca3f; материалы Hero Image: 58dca3f. Подписанный .iq не изменён, SHA-256: 5bcc69d34452e5a45d27665f295f6d07e229ce6a89027d8af2f3205c9049230f. Предыдущие документы описывают подготовку кандидата; актуальный статус продолжения и слияния — в задаче TSV-35.
