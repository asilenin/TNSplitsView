# TN Splits View — страница проекта

Поле данных Connect IQ для бега на часах Garmin (74 модели манифеста: сенсорные с API 4.1+ — TSV-21, и без тача
с API 3.2+ — fr255, fēnix 6 Pro, fr245/645/745/945 — TSV-24): список кругов с цветом по темпу и ввод замера лактата
тапом (только на сенсорных) с записью в файл тренировки developer-полем. Опубликовано в Connect IQ Store.
Записанный лактат читает коннектор проекта «Runner MCP» (репозиторий `Garmin-TN-MCP`). Порядок работы чата —
общий поток (`~/.claude/CLAUDE.md`, навыки `flow`, `take`, `ship`); здесь — только своё у проекта.

## Хрупкое место — запись лактата

Record-поле FitContributor повторяет последнее значение в каждой следующей записи. Поэтому значение замера идёт
только через буфер `_pending`, который пишет `compute` раз в секунду: держит его `_holdSec` секунд (10 — Garmin
прореживает поток на длинных тренировках) и дальше пишет 0.0. `setData(null)` роняет приложение; запись вне
`compute` теряется в гонке (TSV-2). Номер поля 1, тип float, единицы mmol/L, `resources/fit/fit.xml` — по ним
поле находит коннектор Runner MCP (`garmin_raw/backend.py`, `_LACTATE_APPIDS`; appID в данных — присвоенный
Store `76c7981c-29ee-4a5a-8af0-e97eb4a2a9fc`). Меняешь номер, тип, единицы или частоту записи — это
задача и в Runner MCP: связь называют комментарии обеих задач.

Остальные решения, найденные пробами на часах (ввод только `onTap`, эмодзи только UTF-8 в исходнике, раскладка
долями экрана), — `docs/PROJECT_TN_SplitsView.md`, справочник на 13.07.2026. Он описывает запись ещё без удержания
10 секунд, настройки — без `useTouch` и режима «Cycle by timer», appID — манифестный.

## Оформление (TSV-18)

Язык циферблата TN Watch Face: один шрифт Courier Prime Bold, цвет только у темпа и замера, тёмная и светлая темы
(настройка «Тема»). Шрифты — растровые, `tools/make_fonts.py` (Pillow) кладёт их в `resources-454` (fr965, fr970) и
`resources-260` (fr255, fr955); `monkey.jungle` выбирает папку по экрану. Раскладка в пикселях макета 454
(`design/mockup.html`), в коде `sc()` масштабирует. Поменял размер шрифта — перезапусти скрипт и поправь высоты цифр
в `txt()`. Глазами проверялся только fr965.

## Копия и ветка

- Своя копия соседней папкой: `git worktree add ../TNSplitsView-<slug> -b <slug> main`. Основная копия
  `~/TNDev/TNSplitsView` стоит на `main`: из неё владелец собирает приложение в VS Code — в ней только сливают.
- Сообщение коммита начинается с идентификатора задачи («TSV-16: …»).
- Ключ подписи `~/garmin/developer_key` — только путём в команде сборки; не копировать, не печатать, не коммитить.

## Чем проверять

Сборка под пять моделей, из корня копии; готово, когда каждая пишет `BUILD SUCCESSFUL`. fr645m — самая старая
прошивка манифеста (API 3.2) и меньше всех памяти (64 КБ): ловит вызов API новее 3.2 без проверки `has` (TSV-24).

```bash
SDK="$HOME/Library/Application Support/Garmin/ConnectIQ/Sdks/connectiq-sdk-mac-9.2.0-2026-06-09-92a1605b2"; for d in fr255 fr645m fr955 fr965 fr970; do "$SDK/bin/monkeyc" -d $d -f monkey.jungle -o /tmp/tsv_$d.prg -y ~/garmin/developer_key -w 2>&1 | tail -1; done
```

Предупреждения v16, с которыми код пришёл в git: 31 «Cannot determine if container … is using container type»
(проверка типов не выводит тип массивов) и для fr255, fr645m, fr955 — иконка 65×65 масштабируется до 40×40. Новое
предупреждение сверх них — повод разобраться; полный вывод — та же команда без `| tail -1`. Поведение (тап, ввод лактата, запись в файл) проверяется только на часах: в симуляторе данные
активности серые и тап поля не работает. Такую проверку чат просит у владельца: какую сборку поставить, что сделать
на пробежке и что должно получиться; запись лактата подтверждает замер, прочитанный коннектором Runner MCP.

## Чем выкатывать

Прода нет: «выкат» — слияние в `main` и `git push` на GitHub (`asilenin/TNSplitsView`, публичный). Из «Выката»:

1. В ветке `git fetch && git merge origin/main`, сборка под четыре модели.
2. В основной копии `git checkout main && git pull --ff-only && git merge --no-ff -m "TSV-N влит: <что изменилось
   для бегуна>" <ветка> && git push`. Сообщение мерж-коммита — заметка о выпуске.
3. Уборка: `git worktree remove ../TNSplitsView-<slug>`, `git branch -d <ветка>`.

Выпуск в Store — отдельное решение владельца, не часть выката: пакет `.iq` собирает и загружает на
apps.garmin.com он сам (версия приложения — в кабинете разработчика). Задача, которая должна дойти до часов
бегунов, закрывается после выпуска в Store; до него — «⏳» и вопрос владельцу.
